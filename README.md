# Apple TV Style Android TV Launcher

مشروع Launcher تجريبي لأجهزة Android TV / Google TV، مكتوب بـ Kotlin ويستخدم Gradle Kotlin DSL.

## البناء عبر GitHub بدون Android Studio
1. أنشئ مستودع GitHub وارفع محتويات هذا المجلد إلى الفرع `main`.
2. افتح تبويب **Actions** وانتظر اكتمال `Build Android TV Launcher APK`.
3. افتح نتيجة التشغيل الناجح، ثم نزّل ملف `app-debug` من قسم **Artifacts**.
4. ثبّت APK على جهاز التلفزيون، ثم اختر التطبيق كواجهة Home افتراضية من إعدادات الجهاز إذا أتاح النظام ذلك.

## البناء محلياً
يتطلب JDK 17 وGradle 8.9:
```bash
gradle assembleDebug
```
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات مهمة
- يستخدم التطبيق `QUERY_ALL_PACKAGES` مع استعلامي `CATEGORY_LAUNCHER` و`CATEGORY_LEANBACK_LAUNCHER` لعرض التطبيقات القابلة للتشغيل، بما فيها كثير من تطبيقات sideloaded. قد تفرض إصدارات Android أو سياسات الشركة المصنّعة قيوداً إضافية.
- لا تضمن كل التطبيقات توفير Android TV banner؛ عند غيابه يستخدم التطبيق أيقونة التطبيق.
- الرف العلوي يعرض أول 8 تطبيقات أبجدياً حالياً، وليس نظام مفضلة قابل للتخصيص بعد. يمكن تطويره لاحقاً بإضافة حفظ اختيارات المستخدم.
- لا يمكن ضمان أن كل جهاز يسمح بتعيين Launcher خارجي أو اعتراض زر الرجوع بالطريقة نفسها؛ ذلك يعتمد على إصدار النظام وبرمجيات الشركة المصنّعة.
- الشعار النصي  tv مستخدم كعنصر تصميمي فقط؛ المشروع غير تابع لشركة Apple ولا يستخدم واجهة tvOS أو أصولها الأصلية.
- تم اختيار `targetSdk 28` لتوافق أوسع مع أجهزة التلفزيون القديمة. قبل النشر العام، راجع متطلبات Google Play وسياسات حزم التطبيقات والخصوصية.
